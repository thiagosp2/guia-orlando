# Guia Orlando v23 — Histórico por horário

Na seção "Histórico por data e horário específico", após consultar a data, selecione múltiplas atrações e o intervalo do gráfico (padrão 10h–18h). O gráfico compara linhas por atração em amostras de 15, 30 ou 60 minutos; tabela de estatísticas e exportação CSV. O histórico continua sujeito aos limites da API e à idade máxima de cada observação.
