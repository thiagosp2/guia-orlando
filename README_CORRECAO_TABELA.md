# Correção da tabela de recomendações

O aviso de atrações imperdíveis excluídas por ultrapassarem o limite de fila não oculta mais a tabela de atrações elegíveis.

- Com atrações elegíveis: exibe aviso (se houver), próxima sugestão e tabela.
- Sem atrações elegíveis: exibe aviso (se houver) e mensagem informativa, sem tentar acessar a primeira linha vazia.
- A tabela de todas as atrações permanece visível.

Execute: `python -m streamlit run app.py`.
