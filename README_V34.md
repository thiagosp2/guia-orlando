# Guia Orlando v34 — duas opções automáticas no PDF

- Planejar viagem apresenta a primeira e a segunda melhores combinações sem botões de seleção.
- Cada opção mostra suas datas, parques e programação de atrações, com edição independente.
- PDF único inclui opção 1 e opção 2, cada uma com datas, atrações, horários e avisos.
- CSV único contém coluna Opção.
- Caso não exista segunda combinação viável, a interface explica a limitação e o PDF apresenta somente dados válidos.
- Base: v33; v29-v33 preservadas.
