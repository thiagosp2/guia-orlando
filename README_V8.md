# Disney Guia Virtual v8 — Melhores dias por atrações escolhidas

Na aba **Melhores dias**, selecione as atrações individualmente para cada parque. Sem seleção, o cálculo utiliza todas as atrações que têm dados históricos de fila. As médias são calculadas a cada hora (10h–18h, Orlando) entre as atrações observadas e depois agregadas por dia. A pontuação para distribuir os parques considera apenas esse conjunto de atrações, com comparação normalizada entre parques.

Dados faltantes e atrações fechadas não são tratados como filas de zero minuto. A tabela apresenta cobertura média de observações. O histórico disponível na API pode não incluir todos os dias da semana e não prevê feriados, eventos especiais, horários futuros ou Lightning Lane.

Execute `python -m pip install -r requirements.txt` e `python -m streamlit run app.py`.
