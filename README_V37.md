# Guia Orlando v37 — Opções por parque e por dia da semana

A primeira opção usa o melhor dia da semana histórico disponível de cada parque; a segunda utiliza o melhor dia alternativo da semana para cada parque. Datas diferentes do mesmo dia da semana não são consideradas alternativas. Os dias são conciliados para evitar visitar dois parques na mesma data; quando há conflitos, prioriza-se a soma dos rankings individuais de cada parque.

Cada opção gera seu próprio roteiro por atração, consultando os melhores horários históricos do dia da semana escolhido, e o PDF contém ambas quando disponíveis.

Importante: as recomendações dependem de cobertura histórica real. Sem dados válidos para um segundo dia da semana, o sistema informa a limitação. A API real e a interface Streamlit devem ser verificadas no computador do usuário.
